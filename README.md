# Офис агентов v3 (бета)

![Офис агентов — шесть отделов вокруг Базы знаний и панель задач](assets/readme-hero.jpg)

Изометрический 3D-офис, где ИИ-агенты выполняют реальные задачи через вашу учётную запись Claude.

Шесть отделов, 35 агентов, строка постановки задач и База знаний из вашей папки заметок. Напишите задачу — офис выберет исполнителя, агент прочитает заметки, воспользуется подключениями Claude Code, выполнит работу и сохранит результат обратно. Всё работает на вашем компьютере.

**Бета-версия.** Основной цикл работает полностью, но возможны шероховатости. Сообщайте о них в Issues.

## Требования

- macOS или Linux; в Windows используйте команды `npm` напрямую, потому что `./setup` написан для Bash;
- Node.js 20+ — https://nodejs.org;
- Git;
- **Claude Code** с активной учётной записью Claude либо `ANTHROPIC_API_KEY`.

## Установка

```bash
git clone https://github.com/ajsahni/agents-office.git
cd agents-office
./setup          # проверка окружения, установка, сборка и первый запуск
npm start        # → http://localhost:4520
```

Без `./setup`: `npm install && node build.mjs && npm start`.

## Первые пять минут

1. Откройте http://localhost:4520. Надпись **РАБОТАЕТ · CLAUDE** означает подключение к серверу. Файл `dist/command-centre-v2.html` можно открыть напрямую в демонстрационном режиме.
2. Выберите отдел, напишите задачу обычными словами и нажмите **ДОБАВИТЬ**. Claude выберет агента; результат появится в чате и сохранится заметкой в Базе знаний.
3. Нажмите на агента, чтобы поговорить. Команда `доработай: сделай короче` изменит последний результат и сохранит замечание.
4. Нажмите **G** или Базу знаний, чтобы открыть граф заметок.
5. Верхняя панель показывает подключения Claude Code. При использовании логотип и линия нужного отдела подсвечиваются.
6. Первые ответы будут качественными, но типовыми. Подключите свои заметки и обучите агентов через брифы и навыки — тогда офис станет вашим.

## Подключения

Панель **ПОДКЛЮЧЕНО** показывает результат `claude mcp list`: Gmail, Slack, Notion, Google Drive и другие MCP-серверы. Сервер без авторизации отображается серым и не выдаётся агентам. Кроме подключений агенты могут пользоваться веб-поиском.

Агенты не получают Bash, файловые инструменты или субагентов. Их правило: читать можно свободно; отправлять, публиковать, платить, удалять или менять внешние данные можно **только когда задача прямо требует именно этого действия**. В результате и сохранённой заметке перечисляются использованные инструменты.

Доступ настраивается в `office.config.json`:

```json
"mcp": { "allow": [], "deny": ["Stripe"], "departments": { "Slack": ["emails", "ops"] } },
"tools": { "web": true, "browser": true },
"teams": { "enabled": true, "max": 4 }
```

Пустой `allow` разрешает все подключённые серверы. `deny` оставляет сервер на панели, но не выдаёт агентам. `departments` ограничивает подключение отделами. `tools.web` и `tools.browser` управляют веб-поиском и Chrome. При `ANTHROPIC_API_KEY` без входа Claude Code агенты работают только с заметками.

## Настройка агентов

35 агентов описаны в `office.agents.json`: идентификатор, отдел, имя, роль, обязанности и инструменты. Можно менять имя, роль, обязанности, инструменты, бриф, модель и усилия. Отделы, руководители и количество мест фиксированы; новый тип агента создаётся переименованием подходящего места.

Проще всего попросить Claude Code:

```text
claude
> Переименуй агента РАССЫЛКА в ЗАМЕТКИ ПОДКАСТА. Он готовит описание выпуска
  и пост для LinkedIn, используя Google Drive.
> Адаптируй отдел Продаж под оптовых клиентов и перепиши обязанности агентов.
> Разреши всем агентам Финансов использовать только Xero.
```

Claude читает `CLAUDE.md`, записывает изменения в игнорируемый Git файл `office.agents.local.json` и запускает `npm run check`.

```json
{ "agents": [
  { "id": "newt", "name": "ЗАМЕТКИ ПОДКАСТА", "role": "Редактор подкаста",
    "does": "Готовит описание выпуска и публикацию для LinkedIn.",
    "tools": ["google drive"],
    "brief": "Описание — пять тезисов и цитата. Пост начинается с цитаты." }
] }
```

Изменения `id`, `department` и `lead` игнорируются. Приоритет источников: `office.agents.json` → `<brain>/Agents Office/agents.json` → `office.agents.local.json`.

## Как обучить агентов вашей работе

- **Бриф** — постоянные указания одному агенту: тон, ограничения, эскалация и инструменты.
- **Навык** — папка `<brain>/Agents Office/skills/<name>/` с `SKILL.md`, этапами, структурой, правилами, шаблоном и примерами.

```markdown
---
name: proposal
description: Как мы готовим предложение клиенту
agents: [piper]
---
# Подготовка предложения
Используй навык для документов, которые клиент принимает или отклоняет.
1. Бери цены из `10-Business/offer-ladder.md`; не придумывай их.
2. Следуй `template.md` раздел за разделом.
- Всегда три варианта; рекомендуй средний.
```

Пользовательские навыки хранятся в Базе знаний и действуют со следующей задачи без перезапуска. Примеры находятся в `skills/`. Полное руководство: [SKILLS.md](SKILLS.md).

### Интервью с руководителем

Откройте чат руководителя и напишите **«настроить»**. Он задаст пять вопросов об отделе, процессе, хорошем результате, запретах и инструментах, затем создаст брифы и один навык. Команды: «пропустить», «готово», «отмена». До последнего ответа ничего не записывается.

### Обучение на исправлениях

Команда `доработай: …` сохраняет замечание в `<brain>/Agents Office/feedback/<agent>.md` как разовое уточнение или постоянное правило. Файл можно редактировать вручную. Полноценный процесс лучше перенести в навык.

## Сценарии: автоматическая работа по расписанию

Сценарий запускает задачу автоматически: по будням в 08:00, каждый понедельник или каждый час. Сейчас сценарии доступны для **Почты, Финансов и Продаж**.

Создать сценарий можно четырьмя способами:

- написать в строке: `по будням в 8:00 разбирай входящие и сообщай, что требует моего внимания`;
- включить **ПОВТОР** и выбрать периодичность;
- попросить руководителя отдела в чате;
- записать сценарий через Claude Code в `<brain>/Agents Office/routines.json`;
- выбрать день календаря и включить повторение.

В панели у сценария есть обратный отсчёт и кнопки «ЗАПУСТИТЬ», «ПАУЗА», «УДАЛИТЬ». Только читающий сценарий завершается самостоятельно. Отправка, оплата или внешнее изменение по умолчанию переводит задачу в **ЖДЁТ ОДОБРЕНИЯ**. Пропущенный во время сна компьютера запуск выполняется один раз после возвращения и помечается как опоздавший. Сервер `npm start` должен работать; открытая страница не обязательна.

Поле задачи растёт вместе с текстом: Shift+Enter добавляет строку, Enter создаёт задачу. Кнопка ⤢ или ⌘⇧E открывает большой редактор; ⌘↵ отправляет, Esc закрывает.

## Календарь

Нажмите **P** или кнопку «КАЛЕНДАРЬ». Здесь показаны завершённые, текущие и запланированные задачи, а также будущие запуски сценариев. Доступны месяц, неделя, фильтры, поиск и список сценариев.

Нажмите на день, чтобы создать разовую задачу или сценарий с этой даты. Разовая задача выполняется сервером в указанную минуту, даже если страница закрыта. Нажатие на карточку открывает результат, управление сценарием или отмену запланированной задачи.

## Команды агентов

Нажмите **КОМАНДА** или напишите «всей командой». Руководитель разделит задачу между подходящими агентами, они выполнят части параллельно и оставят друг другу заметки, после чего руководитель соберёт итог. Число участников ограничивается `teams.max`.

Одна командная задача расходует несколько запусков Claude: план руководителя, по одному запуску на участника и финальная сборка. Брифы, навыки и правила внешних действий продолжают действовать. Для сценария используется `"team": true`.

## Claude in Chrome

При `"browser": true` агенты могут работать в вашем Chrome на сайтах, где вы уже вошли: читать страницы, заполнять формы и выполнять прямо запрошенные действия. Один раз выполните `claude --chrome` и подключите расширение Claude in Chrome. На панели появится плитка Chrome.

Доступ можно отключить через `"browser": false` или `"deny": ["Chrome"]`. Главное правило действует и в браузере: чтение свободно, внешнее изменение — только по прямому запросу.

## Выбор модели и расход тарифа

Доступны Sonnet, Opus и Fable. Модель можно задать офису, агенту, сценарию или отдельной задаче. Приоритет: задача → сценарий → агент → офис. Аналогично задаётся `effort`: `low`, `medium`, `high`, `xhigh`, `max`.

Верхняя панель показывает использование текущей сессии и недели, если Claude Code возвращает эти данные, а также локальный подсчёт токенов офиса. Командная работа расходует больше запусков, чем задача одного агента.

## Оформление под себя

- `office.config.local.json` — локальные настройки офиса;
- `office.agents.local.json` — имена, роли, обязанности, брифы и инструменты;
- поле `brain` — путь к вашей Базе знаний;
- папки навыков — процессы, шаблоны и примеры;
- файлы обратной связи — выученные правила.

Не редактируйте собранный HTML вручную: меняйте исходники и запускайте сборку.

## Цикл разработки

```bash
npm start        # локальный сервер
npm run build    # сборка dist/command-centre-v2.html
npm run check    # сборка, проверки данных и браузерные smoke-тесты
npm run graph    # перестроение графа заметок
```

После изменения кода всегда выполняйте `npm run check`.

## Конфиденциальность

Офис работает локально. Заметки читаются на вашем компьютере и передаются Claude только в контексте выполняемой задачи. Подключения вызываются через Claude Code с вашими разрешениями. Проект не выдаёт агентам терминал или произвольный доступ к файлам. Перед подключением внешнего MCP-сервера изучите его собственную политику данных.
